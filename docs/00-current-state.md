# 현재 상태

*이 문서는 "지금"의 한 장 요약입니다. 따로 진행 현황이나 로드맵 문서를 두지 않고 여기 한 곳에서 고칩니다.
지난 일은 git 기록과 머지된 PR이 기억합니다. 여기에는 지금 사실인 것만 둡니다.*

## 무엇을 누구를 위해

*두세 문장으로 씁니다. 누가, 어떤 상황에서, 무엇을 얻는지. 자세한 배경이 필요하면 ADR로 링크합니다.*

## 범위와 범위 밖

*지금 하는 것과 하지 않는 것을 나란히 적습니다. 범위 밖은 "아직"인지 "하지 않기로"인지 구분하고, 하지 않기로
했다면 결정 번호를 붙입니다.*

## 지금 되는 것

*사용자가 실제로 할 수 있는 것을 적습니다. 코드가 있다는 것과 쓸 수 있다는 것은 다릅니다. 확인하지 않은 것은
"확인 필요"로 적습니다.*

## 알려진 빈틈

*알고 있는 결함, 빠진 것, 받아들인 위험. 추적 이슈가 있으면 링크합니다.*

## 다음

*다음에 할 일 몇 가지와 그 순서. 오너의 답이 필요한 것은 [02-open-questions.md](02-open-questions.md)의 질문으로
링크합니다.*

## 이정표 (선택)

*남기고 싶을 때만 둡니다. 날짜와 PR 링크만 적고 커밋 해시는 적지 않습니다(squash 머지하면 사라집니다).
PR 번호는 PR을 연 뒤 같은 PR에 커밋을 하나 더해 채웁니다. 머지 뒤에 이 문서를 따로 고치는 PR을 만들지 않습니다.*

**예시 (가상의 할 일 앱)**

> ## 무엇을 누구를 위해
>
> 혼자 일하는 사람이 브라우저 하나로 오늘 할 일을 적고 끝내는 앱입니다. 가입 없이 바로 씁니다.
>
> ## 범위와 범위 밖
>
> - 범위: 할 일 추가·완료·삭제, 마감일, 휴지통.
> - 범위 밖(하지 않기로): 서버 동기화, 계정. 브라우저 저장소에만 둡니다([ADR 0001](adr/0001-example.md)).
> - 범위 밖(아직): 반복 할 일, 알림.
>
> ## 지금 되는 것
>
> - 할 일 추가, 완료 표시, 마감일 순 정렬.
> - 삭제한 할 일은 휴지통에 7일 머뭅니다(D2). 7일 뒤 자동 비우기는 확인 필요.
>
> ## 알려진 빈틈
>
> - 저장소 용량이 찼을 때 저장 실패를 화면에 알리지 않습니다.
